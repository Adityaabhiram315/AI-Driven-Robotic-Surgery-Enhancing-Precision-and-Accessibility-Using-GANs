# AI-Driven-Robotic-Surgery-Enhancing-Precision-and-Accessibility-Using-GANs with GAZEBO


## 📌 Project Summary

This project explores the integration of Artificial Intelligence (AI) into robotic surgery by enhancing the visual perception of surgical systems through high-resolution medical imaging. Leveraging **Enhanced Super-Resolution Generative Adversarial Networks (ESRGAN)**, we improve the clarity and detail of medical images, which directly boosts the precision and responsiveness of robotic arms in simulated surgical tasks.

Through a combination of **machine learning**, **robotic control systems**, and **simulation using ROS and Gazebo**, the framework aims to demonstrate how visual enhancement can lead to safer, faster, and more accurate surgical interventions—even in complex and unpredictable environments.

---

## 🎯 Key Objectives

- **Enhance low-resolution medical images** using ESRGAN for better anatomical visibility.
- **Evaluate robotic performance** (e.g., grasping, tool navigation) under both original and enhanced image inputs.
- **Simulate realistic surgical environments** using ROS and Gazebo.
- **Measure improvements** across metrics like task success rate, tool path accuracy, and execution time.
- **Advance surgical training and accessibility** through open-source, data-driven simulations.

---

## 🔍 Core Features

- **Super-Resolution Imaging**: Application of ESRGAN to medical datasets for high-fidelity image enhancement.
- **AI-Based Vision and Planning**: Real-time perception and adaptive decision-making using machine learning.
- **ROS & Gazebo Simulation**: A controlled, virtual surgical environment for experimentation and testing.
- **Quantitative Evaluation**: Rigorous comparison of performance with and without enhanced images.
- **Training & Accessibility Focus**: Modular, scalable design aimed at broadening access to robotic surgery systems.

---

## 📦 Technologies Used

- **Machine Learning & GANs**: ESRGAN for medical image super-resolution.
- **ROS (Robot Operating System)**: For robotic control and communication.
- **Gazebo**: For realistic 3D surgical simulation and testing.
- **Medical Imaging Datasets**: Public datasets such as NIH Chest X-rays and TCIA scans.

---

## 📊 Impact and Contribution

This research addresses critical gaps in AI-driven surgical robotics, including:

- Limited annotated surgical data
- Low-quality imaging
- Lack of real-time feedback
- Underdeveloped training environments
- High system cost and limited accessibility

By enhancing perception with ESRGAN and evaluating its real-time impact in simulation, this project proposes a cost-effective and scalable step forward for next-generation surgical robotics.
